## Decision summary

- The 12-slide Business Review replacement is generated from a new source file using new text and native PowerPoint shapes. It does not open or copy the former deck, its masters, layout, fonts, or assets.
- The local Idea Document, Pitch Deck, and Architecture PDFs have been re-exported from their tracked DOCX, PPTX, and SVG sources using pinned Noto Sans and Noto Sans Symbols fonts under SIL Open Font License 1.1. Their source files are unchanged. The replacement PDFs preserve source text; the Idea PDF uses a temporary 95% point-size scale to retain its existing eight-page pagination.
- The PDF exports use fonts and licenses downloaded into a temporary directory, verified by SHA-256, and resolved by Fontconfig. No standalone font binary is added to the repository; only Noto font subsets are embedded in those PDFs. The editable Office files contain font-family references but no embedded font binaries.
- No photographs, screenshots, external icons, logos, decorative artwork, or imported diagrams are used in the replacement deck. The name “DrillLoop” appears as ordinary text; no organization logo or organization branding is used.
- The old template-based Business Review remains in commit `3bc0c71d7038dc31806b03bcc7fbbf8e62900aad` and earlier history. The current branch tip replaces its files, but does not remove that historical copy or clear its template/font rights.
- `frontend/scripts/capture_demo.mjs` confirms the three screenshots are Playwright captures of the local DrillLoop UI with synthetic demo data. The project owner attests to maintaining the original screenshots and branding, subject to applicable contractual obligations. The UI includes `lucide-react` 0.468.0 icons under ISC. CSS requests Avenir Next first, but the capture does not record the font the browser actually resolved; the PNGs contain rasterized glyphs and no standalone font binary. Verify the resolved font's terms or re-capture with pinned Noto Sans.
- Local Idea/Pitch/Architecture PDF font provenance is now verified. Business Case and Evaluation PDFs reference only standard PDF Base-14 fonts and embed no font programs. The owner attestation covers original project materials; the Idea attribution accuracy, Business Case author metadata/factual review, external-source summaries, screenshot font provenance, distribution model, and publication scope remain undecided.

All seven published artifact paths listed in the table below already exist in the `main` baseline at `78f2d594a88e5512672720f311aa8e1dceb344f1`, which Phase 10 confirmed as the public baseline. Replacing files in this worktree does not remove their earlier public versions from Git history, forks, or cached downloads.

## Historical disclosure: Pitch Deck image descriptions

Repository evidence confirms that `DrillLoop_Pitch_Deck.pptx` at public-baseline commit `78f2d594a88e5512672720f311aa8e1dceb344f1` and its earlier ancestor `6fd20166e921` each contain a developer-machine absolute path in three image-description fields on slides 3, 5, and 7. The corresponding Pitch Deck PDFs at those commits contain no matching absolute-path marker. The current release candidate contains zero such image descriptions. The earlier PPTX versions are reachable through existing Git history and may also remain in repository mirrors, cached downloads, forks, or clones; a normal follow-up commit will not erase those copies.

The values reveal a local account and nested working-directory/project labels. The review found no credential-like assignment, email address, or private/loopback endpoint in the historical package text and metadata. That is evidence about the inspected Office package, not proof that the directory labels are non-confidential. The current candidate removes the path from new-release content. No severity classification is made here.

Security owner decision required: (1) accept the historical local-directory disclosure and record the rationale; or (2) request a separate history-remediation proposal after evaluating the value of removing old refs against risks to existing clones, forks, cached artifacts, commit IDs, and collaborators. Normal updates clean the current branch tip but leave earlier reachable commits intact. Any history rewrite would require separate authorization, coordination, and remote operations; none was performed or is authorized by this task.
